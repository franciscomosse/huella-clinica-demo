# Huella Clínica · demo

Demo interactiva de **Huella Clínica**, un producto imaginario del Grupo 1 (MBA en Salud): receta digital con Face ID para frenar las recetas a nombre de un afiliado que retira otra persona.

Probala acá: https://franciscomosse.github.io/huella-clinica-demo/

- Nombres, matrículas y códigos son ficticios; el Face ID es simulado.
- Todo queda en tu navegador: lo que hacés no lo ve nadie más. En una compu podés abrir cada pantalla en otra pestaña y se sincronizan.
